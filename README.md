
#  GodViewer 上帝视角

[English](README.en.md) | 中文

- 一款基于 **Xposed / LSPosed** 的「上帝视角」运行时视图调试工具。
- 模块已全量迁移到 **libxposed API 102**（`META-INF/xposed` 现代入口，不再依赖旧 XposedBridge API）；目标设备 Android 16 + LSPosed 2.1.0，**回归验证进行中**
- 不用重启应用、不用系统作用域，直接在目标应用上**点一点就能把它的 UI 改成你想要的样子**，并且具有**持久性**。
- **Telegram 讨论群**：[t.me/GodViewer](https://t.me/GodViewer) —— 欢迎进群交流、反馈问题与提建议

##  能干什么

-  **点哪改哪**：触摸屏幕直接选中视图，比 F12 还顺滑
-  **属性随便动**：尺寸 / 边距 / 内边距 / 可见性、`TextView` 文本与最大行数、`ImageView` 图片 URL 与缩放
-  **隐藏 & 重置**：一键隐藏视图；改过的视图随时恢复原样
-  **改了就不丢**：修改存成规则，目标应用重启 / 杀进程 / 重启手机后自动重放
-  **本体通知入口**：编辑模式入口统一为**上帝视角本体通知**，主页开关打开后才显示；点通知上的「开启 / 撤销 / 管理规则」即可操作
-  **一键清空某个应用的规则**：规则页进入某个应用后，右上角菜单可删除该应用的全部规则

## 使用方法

1. **LSPosed** 勾选目标应用并重启
2. 打开**上帝视角**，在**主页打开「本体通知」开关**（首次会申请通知权限）
3. 打开目标应用，下拉通知栏点本体通知上的「**开启**」
4. 点一下想改的控件 → 改 → **应用**，完事 或 直接**隐藏**
5. 编辑完在弹窗点「**退出编辑模式**」→ 恢复正常使用，干净利落

## 工作原理

模块注入目标应用进程，点击被拦截后弹出编辑弹窗；修改以 JSON 规则存在**目标应用自己的数据目录**，重启自动重放。不注入系统服务、不需要系统级权限，只在你勾选的目标应用里活动。

## 🛠 构建

```bash
./gradlew assembleRelease
```

产物：`app/build/outputs/apk/release/app-release.apk`（需 JDK 17 + Android SDK platform 35）
